# Security policy

## Reporting a vulnerability

Email security@cantivia.com with a description of the issue, the version affected,
and the steps to reproduce it. Please do not open a public issue for a security
report.

We will acknowledge your report and keep you informed while we investigate.

## Supported versions

Security fixes are made in the latest 0.x release. Upgrade to it to receive them.

## API keys

Never commit an API key or ship one in browser code. If a key is exposed, revoke it
on the Cantivia dashboard and create a new one.
